Manage Training Modules

Add, rename, reorder (↑ ↓) or delete modules here. When you click Save Changes, the updated module list appears on every worker's card (existing workers keep their data; new modules start blank). Nothing changes until you save. The Hindi Meaning column can be edited, or cleared with 🗑 to delete it.
⚠ Deleting a module also removes its date / trainer / sign data for all workers. Admin login is required to add, delete or save modules.

💾 Backup & Restore

Data is stored inside the browser of each device/website address. If you open the hosted site and see no data, open your old copy, click Download Backup, then on the hosted site click Restore Backup.

☁ Cloud Setup — Google Sheet & Drive

Ek baar setup karo. Uske baad data Google Sheet me, photos Google Drive me aur website par — teeno jagah rahega. Sync apne aap hota hai (har save / delete ke baad).
  1. Code copy karo (neeche button) → script.google.com kholo → New project → pehle ka saara code hata kar paste karo → Save.
  2. Upar function list me setup select karo → Run → Allow (permissions). Isse Google Sheet aur Drive folder "Safety Training Cards" apne aap ban jayenge.
  3. Deploy → New deployment → Web app → Execute as: Me → Who has access: Anyone → Deploy → Web app URL copy karo (/exec par khatam hota hai).
  4. URL neeche paste karo → Save & Test.
• Connect Link dusre phone / computer par kholne se wahan bhi URL apne aap set ho jata hai.
• Data website se hi edit karo (Sheet me haath se badlav website me wapas nahi aata; Sheet se row delete karne par bhi website data safe rehta hai jab tak bohot saari rows na hatayi jayein).
• Sheet tabs: Workers (profile + progress), Training Records (module-wise record), Config, Deleted. Drive me daily JSON backup bhi banta hai.
