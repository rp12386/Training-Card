Setup Guide (one-time only)

  1. Sign in to your Google account and open script.google.com → New project → name it Safety Training Cards.
  2. Delete the existing code in the editor and paste the code below (Copy Code button) → press Ctrl+S to save.
  3. (Optional) In the code, set a secret word for ACCESS_KEY and enter the same word in the Access Key box above. Only your website will then be able to send/receive data.
  4. In the function dropdown at the top of the editor, select setup → ▶ Run → Review permissions → your account → Advanced → Go to project (unsafe) → Allow. (Google shows this warning because the script is your own.) This automatically creates a Google Sheet named Safety Training Cards and a Drive folder named Safety Training Photos.
  5. Deploy → New deployment → ⚙ choose type Web app → Execute as: Me  |  Who has access: Anyone → Deploy → copy the Web app URL.
  6. Paste that URL in the Web App URL box above and click Save & Connect (admin password required). The website will test the connection and send all workers to the Sheet.
After changing the code: Deploy → Manage deployments → ✎ Edit → Version: New version → Deploy (the URL stays the same).

How it works

Google Sheet: each worker gets one row (name, CLIMS ID, folder, grade, agency, area, modules completed) plus a separate column for every training module — with date, trainer and sign.
Google Drive: worker photos are saved in the Safety Training Photos folder. By default the photo link is viewable by anyone with the link, so photos show on other devices. To keep photos private, set PUBLIC_PHOTOS = false in Code.gs (photos will then show only on the device where they were uploaded).
Auto sync: cards are sent to the cloud as soon as you save/delete them; sync also runs when the page opens, when the internet returns, and every 3 minutes. If you are offline, data stays safe in this browser and uploads automatically later.
Training modules: the module list is also saved in the cloud, so changing modules on one device updates the others.
Note: only deleting a row in the Sheet is reflected on the website. To change data, edit it on the website (the training columns in the Sheet are view-only).
